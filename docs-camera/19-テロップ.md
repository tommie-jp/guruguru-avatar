# テロップ（CNN 風・下部クロール）

配信映像（透過オーバーレイ）の最下部に、CNN の「BREAKING NEWS」のような**流れる文字列
（クロール）**のテロップ帯を重ねる機能。文言・背景色・文字色・流れる速さを設定でき、手元で
変えた内容を WS 中継で OBS 側へ送って表示する（顔ポーズ・お絵かきと同じ `/__relay` 経路に相乗り）。

**お絵かき（[18-お絵かきオーバーレイ.md](18-お絵かきオーバーレイ.md)）とは独立**したレイヤーで、
互いに干渉しない（テロップを消してもお絵かきは残る／その逆も同じ）。

## 仕組み（操作と表示を分ける）

OBS のブラウザソースは基本マウス操作できないので、**操作（打ち込む）と表示（OBS）を別ページに
分ける**（お絵かきと同じ考え方）。

- **操作側（tx / local）**: ふだんのブラウザのタブで開く。下部のコントロールで文言・色・速さを設定。
- **表示側（rx = OBS のブラウザソース）**: 受信した設定でテロップ帯を描くだけ（操作UI無し・透過）。

```text
[手元 tx]  index.html?tx           ← コントロールで文言/背景色/文字色/速さ/表示ON・OFF
   │ 設定が変わるたび {text,bgColor,textColor,speed,visible} を送信
   ▼
WS 中継 /__relay （pose・お絵かきと同じ経路。中継は素通し）
   │ 後から OBS が繋がっても現在の設定を再送（取りこぼし防止）
   ▼
[OBS rx]  index.html?rx&obs        ← 受信した設定で帯を描く（透過）
```

クロールのアニメーションは **rx 側が受信した設定から CSS でローカルに動かす**（毎フレームは
流れない＝設定を変えたときだけ WS に流れる）。文言を2コピー並べて継ぎ目なくループし、短い文言でも
バー幅ぶんの間隔で繰り返す。見かけの速さは文言の長短によらず一定になるよう幅から所要時間を算出する。

操作 PC と OBS が同じ Windows 機なら、両方とも `http://localhost:5173/...` で繋げば中継 URL は
共有される（別配線不要）。別 PC 配信は `?relay=<ws(s) URL>` で中継先を明示する
（[16-URLパラメータ一覧.md](16-URLパラメータ一覧.md) の `?relay` 参照）。

## 使い方

テロップは**既定でマウント**され、コントロールは操作側（`index.html` を普通に開く＝local、または
`?tx`）に出る。完全に無効化（レイヤーごと出さない）したいときだけ `?ticker=0`。

```text
# 手元（設定する側）。普通に開けばコントロールが出る（?tx は OBS へ送る場合）
http://localhost:5173/index.html
http://localhost:5173/index.html?tx

# OBS のブラウザソース（表示側）。受信したテロップを表示
http://localhost:5173/index.html?rx&obs

# テロップを完全に無効化したいとき
http://localhost:5173/index.html?ticker=0
```

コントロール（既定ではお絵かきツールバーの少し上に出る）。左端の**ドラッグハンドル（⠿）をつかんで
好きな位置へ移動**できる（位置は localStorage に保存。ハンドルをダブルクリックで既定位置に戻る）。
画面が狭い（スマホ等）ときは帯がブラウザ幅に収まり、入りきらない操作子は**横スクロール**で出せる:

- **表示中 / 非表示** … テロップの表示を切り替える（既定は非表示。押した瞬間に OBS へ即反映）。
- **文言** … 流す文字列。1行（改行は空白に畳む）・最大 300 文字。
- **背景** … 帯の背景色（既定は CNN 風の赤 `#cc0000`）。
- **文字** … 文字色（既定は白）。
- **速さ** … ゆっくり／標準／速い／高速の4段階。
- 文言・色・速さは localStorage に保存され、次回起動時に復元される。

表示 ON にして文言を入れると、手元にも同じ帯がプレビュー表示される（見たままが OBS に出る）。

## 透過について

- テロップ帯は塗るが、**帯以外の領域は塗らない**（レイヤーのコンテナは透明）。既存のステージモード
  （`?obs` / `?rx` の透過）にそのまま乗る。
- 帯はマウス入力を受けない（`pointer-events: none`）ので、下のアバターのドラッグ操作を邪魔しない。
- OBS のブラウザソース設定の「カスタム CSS」既定値
  `body { background-color: rgba(0,0,0,0); }` は**消さない**（消すと不透明になる）。

## セキュリティ

- 中継は無認証 WS（dev 同居は loopback 限定。LAN 公開は `RELAY_EXPOSE=1` のみ）。テロップ設定も
  盗聴・偽注入は可能（数値 pose と同等のリスク）。信頼できる私設網（tailscale 等）で使う。
- 受信側は表示前に設定を検証する（文言は長さ上限＋制御文字除去、色は `#rgb`/`#rrggbb` のみ許容＝
  style 注入を防止、速さは範囲内へクランプ）。不正な値は既定へ落とす。

## 技術メモ

- 実装: `src/ticker-layer.jsx`（テロップレイヤー・DOM/CSS）・`src/ticker-config.js`（`?ticker` 解析と
  設定の正規化・検証）。ライブラリ非依存（お絵かきの fabric とは別・追加依存なし）。
- 同期は `src/face/relay-client.js` / `use-relay.js` の `ticker` メッセージ
  （`{type:'ticker', data:{text,bgColor,textColor,speed,visible}}`）。後着 OBS への再送は
  `need-config`（config・お絵かきと同じ仕組み）に相乗りしている。
- 表示 ON/OFF は即時送信、文言・色・速さは短いデバウンスでまとめ送りする。
- 対象は camera 版（`index.html`）のみ（演出・お絵かきと同様、talk / ぐるぐる版には載せない）。
