# 日付時刻テロップ（時計）

配信映像（透過オーバーレイ）の**右上**に、日付と時刻を出す時計。文字色・背景色・文字サイズを変えられる。
お絵かき（[18](18-お絵かきオーバーレイ.md)）やテロップ（[19](19-テロップ.md)）とは独立したレイヤー。

- 表示形式は `YYYY/MM/DD HH:mm`（例: `2026/07/07 12:34`・24時間・ゼロ埋め）。
- 時刻は**各端末が自分のローカル時刻**を毎秒更新して描く（時刻そのものは中継で流さない）。
  手元（tx）と OBS（rx）が同じ時間帯なら同じ時刻が出る。

## 仕組み（操作と表示を分ける）

テロップと同じく、操作（設定する）と表示（OBS）を別ページに分ける。

- **操作側（tx / local）**: ふだんのブラウザのタブで開く。コントロールで表示 ON/OFF・色・サイズを設定。
- **表示側（rx = OBS のブラウザソース）**: 受信した設定で時計を描くだけ（操作UI無し・透過）。

設定 `{visible, textColor, bgColor, fontSize}` は専用 `clock` メッセージで tx→rx へ送る（顔ポーズ・
お絵かき・テロップと同じ `/__relay` 経路）。後から OBS が繋がっても現在の設定を再送する（need-config）。

## 使い方

時計は**既定でマウント**され、コントロールは操作側に出る。完全に無効化したいときだけ `?clock=0`。

```text
# 手元（設定する側）
http://localhost:5173/index.html
http://localhost:5173/index.html?tx

# OBS のブラウザソース（表示側）
http://localhost:5173/index.html?rx&obs

# 時計を完全に無効化したいとき
http://localhost:5173/index.html?clock=0
```

コントロール（左端の ⠿ ハンドルをつかんでドラッグ移動できる。位置は localStorage に保存）:

- **表示中 / 非表示** … 時計の表示を切り替える（既定は非表示。押した瞬間に OBS へ即反映）。
- **文字** … 文字色（既定は白）。
- **背景** … 背景色（既定は黒）。
- **サイズ** … 文字の大きさ（12〜80px のスライダー）。
- 表示・色・サイズは localStorage に保存され、次回起動時に復元される。

## レイヤー（重なり順）

- 時計はお絵かきオーバーレイ**より下**に描く（`z-index` を下げてある）。お絵かきの線が時計の上に乗る。
- 時計はマウス入力を受けない（`pointer-events: none`）ので、下のアバター操作を邪魔しない。

## セキュリティ

- 中継は無認証 WS（dev 同居は loopback 限定。LAN 公開は `RELAY_EXPOSE=1` のみ）。信頼できる私設網で使う。
- 受信側は表示前に設定を検証する（色は `#rgb`/`#rrggbb` のみ許容＝style 注入を防止、サイズは範囲内へ
  クランプ、表示フラグは厳密な真偽のみ）。不正な値は既定へ落とす。

## 技術メモ

- 実装: `src/clock-layer.jsx`（時計レイヤー・DOM/CSS）・`src/clock-config.js`（`?clock` 解析と設定の
  正規化・検証・`formatClockTime`）。ライブラリ非依存。
- 同期は `src/face/relay-client.js` / `use-relay.js` の `clock` メッセージ
  （`{type:'clock', data:{visible,textColor,bgColor,fontSize}}`）。後着 OBS への再送は need-config に相乗り。
- 時刻は各端末が `setInterval`（1秒）でローカル更新（表示中のみ）。中継で流すのは設定だけ。
- 対象は camera 版（`index.html`）のみ。
